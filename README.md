# مرجع الإشارات الدينية · Religious Signs Reference · Référence des signes religieux

103 Islamic religious terms in Arabic Sign Language, each performed by a drawn avatar, with pages in Arabic, English and French.

<div dir="rtl">

103 مصطلح ديني إسلامي بلغة الإشارة العربية، تؤديها شخصية مرسومة، بصفحات عربية وإنجليزية وفرنسية.

</div>

## Pages

| File | What it is |
| --- | --- |
| `index.html` | Presentation page with links to the three language pages, the acknowledgement and a note on this version |
| `ar.html`, `en.html`, `fr.html` | The list of terms in each language, with search and category filter |
| `ar.html?w=02010` | One term on its own (here: Prayer). Use this form of address for a QR code; it works on all three pages |

## Files

```
index.html              presentation page
ar.html en.html fr.html language pages
assets/app.js           shared script
assets/style.css        shared styles
data/terms.js           terms, categories, Arabic and English text
data/terms.fr.js        French names and meanings
video/<code>.mp4        the clip shown on the page (about 100 KB each)
posters/<code>.jpg      still frame shown before the clip loads
gifs/<code>.gif         the same animation as a GIF, offered as a download (about 2 MB each)
```

To add a term, add a row to `data/terms.js` and `data/terms.fr.js`, then add its `video/`, `posters/` and `gifs/` files named by the term's code.

## About this version

- This is an experimental version. The avatar's movement is extracted from the original videos.
- Finger shapes are approximate in some signs. The original sign video remains the reference, and each term links to it.
- It has not yet been reviewed by Deaf signers or sign language interpreters.
- The signs are those of the Arabic Sign Dictionary for the Deaf; sign languages differ from country to country.
- The short meanings are for general orientation only and are not a religious ruling reference.
